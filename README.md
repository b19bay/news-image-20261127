Friday 27 November 2026, the world in one page. A single-file Python program draws a 1024x1024 broadsheet PNG from six stories verified as events or first reports of 27 November 2026: Black Friday in the US, New Zealand's final election count, chess Game 4 in Geneva, the second Test in Christchurch, Ramayana's advance bookings, and Wall Street's shortened session. Fifteen wrong-day stories (all from Thursday 26 November) are quarantined in a DATE CHECK box instead of being passed off as today's news.

